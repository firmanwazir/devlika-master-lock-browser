# Devlika Master Lock

A Chromium extension (Chrome, Brave, Edge) to lock the browser, specific tabs, or websites with a password.

## Features

- Browser lock on startup and idle
- Specific tab lock
- Specific website/link lock (domain or path)
- Enable/disable toggle for each website rule
- Tab-scoped unlock (new tabs remain locked)
- `Ctrl + Shift + L` shortcut

## Installation

1. Open `chrome://extensions` (or `brave://extensions` / `edge://extensions`).
2. Turn on **Developer mode**.
3. Click **Load unpacked** and select this folder.
4. In the extension details, enable **Allow in Incognito** to prevent bypassing via private windows.

## Usage

- **Set Password**: Enter your password on first run.
- **Lock Browser**: Press `Ctrl + Shift + L` or click the lock button in the popup.
- **Lock Tab**: Right-click on any page -> select **Lock This Tab Only**.
- **Lock Website**: Right-click on any page -> select **Lock Entire Website**, or add domains/links in the popup **Websites** tab.
