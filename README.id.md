# Devlika Master Lock

Ekstensi Chromium (Chrome, Brave, Edge) untuk mengunci browser, tab tertentu, atau website dengan password.

## Fitur

- Kunci browser saat dibuka dan saat idle
- Kunci tab tertentu
- Kunci website/link tertentu (domain atau path)
- Toggle on/off untuk tiap aturan website
- Buka kunci per tab (tab baru tetap terkunci)
- Shortcut `Ctrl + Shift + L`

## Cara Pasang

1. Buka `chrome://extensions` (atau `brave://extensions` / `edge://extensions`).
2. Aktifkan **Mode pengembang** (Developer mode).
3. Klik **Muat belum dibongkar** (Load unpacked), lalu pilih folder ini.
4. Di detail ekstensi, aktifkan **Izinkan dalam mode Samaran** agar tidak bisa di-bypass lewat incognito.

## Cara Pakai

- **Atur Password**: Masukkan password saat browser pertama kali dibuka.
- **Kunci Browser**: Tekan `Ctrl + Shift + L` atau lewat ikon di toolbar.
- **Kunci Tab**: Klik kanan di halaman web -> pilih **Kunci Tab Ini Saja**.
- **Kunci Website**: Klik kanan di halaman web -> pilih **Kunci Seluruh Website Ini**, atau tambahkan domain/link di popup tab **Website**.
